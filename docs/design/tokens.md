# デザイントークン

デザイン方針:

1. 本文が主役
2. コントロールは最小限
3. アクセントは 1 色、マーカーはセピア寄りの黄

`src/app/theme.css` で定義する CSS 変数を用途とともにまとめる。値は同ファイルと一致させること。

## 色（ライト / ダーク）

| 変数 | ライト | ダーク | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#FAF9F6` | `#141311` | 画面全体の背景色 |
| `--fg` | `#1F1D1A` | `#E8E4DC` | 本文・見出しの文字色 |
| `--muted` | `#7A756D` | `#9B958A` | 補足テキストなど控えめな文字色 |
| `--surface` | `#FFFFFF` | `#1E1C19` | カードやボタンなど地の上に重なる面の背景色 |
| `--border` | `#E6E2DA` | `#2E2B27` | 区切り線・枠線の色 |
| `--accent` | `#2F6F8F` | `#7FB3D5` | アプリ唯一のアクセント色（主要ボタンなど） |
| `--accent-fg` | `#FFFFFF` | `#141311` | アクセント背景上の文字色 |
| `--marker-bg` | `rgba(242, 227, 166, 0.55)` | `rgba(201, 162, 39, 0.28)` | 保存済み単語の背景、セピア寄りの黄 |
| `--marker-line` | `#C9A227` | `#C9A227`（ライトと同じ） | 保存済み単語の下線色 |
| `--speaking-bg` | `#EFE7D3` | `#2A2519` | 読み上げ中の文の背景 |

## タイポグラフィ

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--font-body` | `ui-serif, "New York", Georgia, "Times New Roman", serif` | 本文（EPUB 本文）のフォント |
| `--font-ui` | `system-ui, -apple-system, "Hiragino Sans", sans-serif` | UI（ボタンや見出しなど）のフォント |
| `--body-size` | `18px` | 本文の文字サイズ |
| `--body-lh` | `1.7` | 本文の行間 |
| `--ui-size` | `15px` | UI の文字サイズ |

## 余白・形状

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--space-1` | `4px` | 最小単位の余白（アイコンと文字の間など） |
| `--space-2` | `8px` | 小さめの余白 |
| `--space-3` | `12px` | トップバーの縦余白など |
| `--space-4` | `16px` | ボタンの横余白など標準的な余白 |
| `--space-5` | `24px` | セクション間などやや広い余白 |
| `--space-6` | `32px` | 画面レベルの広い余白 |
| `--radius` | `10px` | ボタンなどの角丸半径 |
| `--touch` | `44px` | タップ領域の最小サイズ（ボタン高さ・アイコンボタンの一辺） |
